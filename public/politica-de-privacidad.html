Política de privacidad

Última actualización: 28 de agosto de 2026.

Responsable y finalidad

José Oviedo Kinesiología utiliza los datos ingresados voluntariamente para responder consultas y gestionar solicitudes de turnos.

Datos solicitados

El formulario puede solicitar nombre, teléfono, servicio, fecha, horario y un mensaje opcional. Recomendamos no incluir diagnósticos, estudios ni información clínica que no sea necesaria para coordinar el contacto inicial.

Uso y conservación

Los datos se utilizarán exclusivamente para atender la solicitud y se conservarán únicamente durante el tiempo necesario para esa finalidad y para cumplir las obligaciones aplicables.

Comunicación y seguridad

No comercializamos datos personales. La información se transmite mediante conexiones cifradas y sólo se comparte con proveedores necesarios para gestionar las solicitudes y prestar el servicio.

Derechos y contacto

Podés solicitar información, corrección o eliminación de tus datos escribiendo a kinesiologiadeportivaoviedoad@gmail.com.

Cambios en esta política

Esta política podrá actualizarse cuando se habiliten nuevas funciones o cambien los medios utilizados para gestionar consultas y turnos.
