# Originales de imágenes

Esta carpeta conserva los originales de las imágenes optimizadas y las fotos de
experiencias todavía no utilizadas. No se publica: Vite solo copia `public/`.

Las versiones WebP mantienen la composición y los colores; los filtros y los
encuadres de las tarjetas siguen aplicándose mediante CSS. El logo utiliza WebP
sin pérdida para conservar sus letras y el símbolo de marca registrada.

Para regenerar los archivos publicados desde estos originales:

```sh
npm run images:optimize
```

La foto de entrenamiento asistido proviene de Pexels; su autor y licencia están
documentados en `readaptacion-entrenamiento-source.txt`.
